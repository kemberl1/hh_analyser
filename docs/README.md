## Ключевые принципы

- Сбор данных: **HTML-парсинг hh.ru — основной путь (primary)**; `api.hh.ru` — фолбэк по флагу/при доступности (на момент Phase 2 API недоступен).
- **Relevance Filtering:** нерелевантные вакансии (Fullstack, Backend, PM, QA и т.п.) отсеиваются и не попадают в БД; словари ключевых/стоп-слов конфигурируемы.
- Учёт статистики по дате публикации `published_at`.
- Идемпотентный сбор (dedup по `hh_vacancy_id`).
- Предрасчёт метрик в снапшотах для быстрых дашбордов.
- Заменяемый LLM-провайдер через абстрактный адаптер.
- Итеративная поставка: 7 независимо проверяемых фаз.
